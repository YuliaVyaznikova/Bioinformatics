# Предсказание и парное выравнивание третичной структуры белка

Используются ESMFold, RoseTTAFold2 и jFATCAT-flexible.

## 1. Исходные данные

Анализируемая последовательность содержит 100 аминокислот и находится в файле [`sequence.fasta`](sequence.fasta).

```
MENEDGYMTLSFKNRCKSKQKSKDFSLYPQYYCLLLIFGCIVILIFIMTGIDLKFWHKKMDFSQNVNVSSLSGHNYLCPNDWLLNEGKCYWFSTSFKTWK
```

## 2. Инструменты

| Этап | Инструмент |
|---|---|
| Первое предсказание структуры | ESMFold, Google Colab |
| Второе предсказание структуры | RoseTTAFold2, Google Colab |
| Парное структурное выравнивание | jFATCAT-flexible, [RCSB PDB Pairwise Structure Alignment Tool](https://www.rcsb.org/alignment) |
| Визуализация | PyMOL 2.5.0 |

## 3. Параметры предсказаний

ESMFold использует модель `esmfold_v1` и 3 recycle. Веса модели загружаются непосредственно в вычислительной среде без обращения к ESMFold API. Для совместимости с текущим PyTorch используется сборка OpenFold с флагом C++20 без изоляции сборки.

RoseTTAFold2 использует параметры `RF2_apr23`, MSA через MMseqs2, 6 recycles, 1 модель и random seed 0. Отдельное окружение Python 3.10, PyTorch 2.2, CUDA 12.1 и DGL 2.0 создаётся через `micromamba`. Весь код вычислений находится непосредственно в ноутбуке.

Ноутбуки [`esmfold.ipynb`](esmfold.ipynb) и [`rosettafold2.ipynb`](rosettafold2.ipynb) содержат код, фактические выводы выполнения и визуализацию результатов.

Исходные ноутбуки ColabFold: [ESMFold](https://colab.research.google.com/github/sokrypton/ColabFold/blob/main/ESMFold.ipynb) и [RoseTTAFold2](https://colab.research.google.com/github/sokrypton/ColabFold/blob/main/RoseTTAFold2.ipynb).

| Показатель | ESMFold | RoseTTAFold2 |
|---|---|---|

| Атомы | 837 | 1659 |
| Средняя уверенность pLDDT | 60,176 | 68,506 в шкале от 0 до 100 |

Результаты ESMFold находятся в [`esmfold/`](esmfold/):

- `ptm0.262_r3_default.pdb`: структура в формате PDB.
- `ptm0.262_r3_default.pae.txt`: матрица PAE размером 100 × 100.
- `ptm0.262_r3_default.png`: графики pLDDT, PAE и контактов.

Результаты RoseTTAFold2 находятся в [`rosettafold2/variant39_rf2_X1_86898/`](rosettafold2/variant39_rf2_X1_86898/):

- `rf2_seed0_00_pred.pdb`: структура в формате PDB.
- `rf2_seed0_00.npz`: значения pLDDT, PAE и distogram.
- `settings.txt`: параметры предсказания.
- `msa.a3m` и каталог `msa/`: исходное и обработанное множественное выравнивание.

Обе PDB содержат по 100 остатков, а их последовательности полностью совпадают с исходной.

## 5. Структурное выравнивание

Выравнивание выполнено через RCSB с методом jFATCAT-flexible. Для обеих структур использованы Assembly 1 и Chain A.

| Показатель | Значение |
|---|---|
| Гибкие блоки | 3 |
| Пары выровненных остатков | 77 |
| Покрытие каждой структуры | 77% |
| Длина выравнивания | 103 колонки |
| RMSD | 2,35 Å |
| Sequence identity в ответе RCSB | 0,40 |
| Sequence similarity в ответе RCSB | 0,45 |
| Поле TM-score в ответе flexible alignment | 0,04 |

RMSD, независимо пересчитанный по Cα из экспортированных координат, равен 2,348 Å и совпадает с ответом RCSB после округления.

Файлы в [`alignment/`](alignment/):

| Файл | Содержимое |
|---|---|
| `query.json` | Параметры запроса к RCSB |
| `ticket.txt` | Идентификатор задания RCSB |

| `sequence_alignment.fasta` | Последовательностное представление выравнивания |
| `transformations.json` | Матрицы трансформации для гибких блоков |
| `aligned_esmfold.pdb` | Выровненная часть структуры ESMFold |

Скрипт визуализации: [`visualize.pml`](visualize.pml). ESMFold окрашен в голубой, RoseTTAFold2 в оранжевый.

## 6. Выводы

Предсказания совпадают не полностью, но имеют значительное локальное сходство. jFATCAT-flexible совместил 77 остатков из 100 с RMSD 2,35 Å. На изображениях совпадают несколько спиральных участков и часть складчатой структуры, тогда как отдельные петли и концевые области занимают разные положения.

Уверенность RoseTTAFold2 выше по среднему pLDDT: 68,51 против 60,18 у ESMFold. Оба значения умеренные и не позволяют считать всю структуру одинаково надёжной. Большие значения PAE также указывают на неопределённость взаимного расположения частей модели.

Поле TM-score в ответе flexible alignment следует интерпретировать осторожно. Результат получен с тремя независимыми трансформациями, а обычный TM-score рассчитан для единого глобального совмещения. Поэтому основной вывод опирается на RMSD, покрытие и визуальное совмещение структур.

Итоговый результат показывает частичное согласие двух методов при различиях в отдельных регионах. Более уверенная структура RoseTTAFold2 может служить основной моделью для дальнейшего анализа, а ESMFold выступает независимым методом сравнения.
